# مجلد البيانات (data)

ضع ملفات الإكسيل (.xlsx أو .xls أو .csv) الخاصة بك داخل هذا المجلد لكي يتم تحميلها تلقائياً على الموقع لكل الزوار عند رفعه على GitHub.

### الأسماء المقبولة للملفات:
1. **`data.xlsx`** (ملف مدمج يحتوي على الدفعات والقرعة في شيت واحد أو شيتات متعددة)
2. **`batches.xlsx`** (خاص ببيانات الدفعات ومواعيد الحضور)
3. **`lottery.xlsx`** (خاص ببيانات القرعة وتخصيص الأراضي)

### طريقة التحديث المستقبلي:
كلما كان لديك ملف إكسيل جديد:
1. استبدل أو أضف ملف الإكسيل داخل مجلد `data/`
2. قم بعمل رفع للـ GitHub:
   ```bash
   git add data/
   git commit -m "تحديث بيانات الإكسيل"
   git push
   ```
3. ستقوم صفحة GitHub Pages بتحميل التحديث تلقائياً لكل زوار الموقع!
